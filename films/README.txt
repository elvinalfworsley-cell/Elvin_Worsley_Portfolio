Put the full films in this folder, named exactly like this (MP4, H.264 video, AAC audio):

  gods-arrow.mp4
  yish.mp4
  picnic-pantry.mp4
  birds-arent-real-uk.mp4
  rampressure-360.mp4
  dead-ends.mp4
  isolation.mp4

The site plays films/<name>.mp4 inside the pop-up window when someone clicks "Play full film".
If a file is missing, the site falls back to the YouTube link (if there is one).

Tips: export at 720p or 1080p. In HandBrake use the "Fast 1080p30" or "Fast 720p30" preset,
"Web Optimized" ticked, so the film starts playing before it has fully downloaded.
Upload the whole folder (index.html and films) together to your host.
Check your host's file-size limit per file (for example GitHub Pages: 100 MB, Cloudflare Pages: 25 MB).
